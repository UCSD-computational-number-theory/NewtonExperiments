# Benchmarking

This directory contains the scripts that we used to compare the performance of our implementations in [DeRham.jl](https://github.com/UCSD-computational-number-theory/DeRham.jl) with other existing implementations for computing the zeta functions of smooth projective hypersurfaces. 

- `plane_quintics_magma_timing.m`: This was used to generate the third and fourth columns of Table 1 in our paper. We assume that you have the most updated version of [Magma](https://magma.maths.usyd.edu.au/magma/) installed.
